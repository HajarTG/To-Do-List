#  To-Do List App

Une application web de gestion de tâches intuitive et efficace, construite avec une base de données **MongoDB** pour une persistance des données fiable.


##  Fonctionnalités

-  **CRUD Complet** - Créer, lire, mettre à jour et supprimer des tâches
-  **Catégories** - Organiser les tâches par projets ou priorités
-  **Priorités** - Définir des niveaux d'urgence (Haute, Moyenne, Basse)
-  **Dates d'échéance** - Suivi des deadlines
-  **Statut des tâches** - Marquer comme terminée ou en cours
-  **Filtrage** - Afficher toutes, actives ou terminées
-  **Persistance MongoDB** - Données stockées localement de manière sécurisée
-  **Responsive** - Fonctionne sur desktop et mobile

##  Technologies

- **Frontend** : HTML, CSS
- **Backend** : Python (Flask)
- **Base de données** : MongoDB
- **Design** : Interface minimaliste et moderne

## 🚀 Installation

```bash
# Cloner le repository
git clone https://github.com/HajarTG/To-Do-List.git
cd To-Do-List

# Créer l'environnement virtuel
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# Installer les dépendances
pip install -r requirements.txt

# Lancer l'application
python app.py

### Prérequis
- Python 3.8+
- MongoDB (local ou distant)

### Lancer l'application:

```powershell
python app.py
```

Ouvrir `http://127.0.0.1:5000/` dans votre navigateur.
